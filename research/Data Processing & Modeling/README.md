# Data Processing & Modeling

## Scope

VulZoo, data integration, entity resolution, temporal joins, learning-to-rank/evaluation, discrete-
event simulation, synthetic data, uncertainty, sensitivity, and robustness.

## Candidate searches

- `VulZoo vulnerability dataset multi-dimensional`
- `vulnerability data integration temporal join look-ahead bias`
- `discrete event simulation SOC vulnerability management`
- `synthetic organisation data validation sensitivity analysis`

## Include

Primary dataset papers, reproducible methods, simulation validation guidance, ranking evaluation,
and temporal/panel-data practices applicable to the design.

## Exclude

Models without available features/outcomes, studies leaking future information, purely descriptive
tools without methodology, and synthetic results presented as empirical enterprise evidence.

## Checklist

- [ ] Record schema, time coverage, unit of analysis, and join keys.
- [ ] Assess leakage, missingness, version changes, and reproducibility.
- [ ] Extract calibration and validation methods.
- [ ] Map every method to an RQ/hypothesis.
